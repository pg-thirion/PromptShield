The browser demo remains local-first. The API is for trusted server-side consumers. This release does not provide a trained classifier, general natural-language security judgement, full multi-tenant isolation, distributed rate limiting, or automatic external tool execution. Do not represent synthetic results as independent measured detection rates. The deployment gates in deployment.md still apply.

Run npm test, npm run benchmark, npm run test:browser (requires Chrome) and the Docker smoke workflow. Refer to the GitHub Actions run for observed results. Browser smoke covers representative interaction paths, not all browsers, accessibility checks or downloaded file handling.
